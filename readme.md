## 🚀 Installing <Indigenas_BOT>

To install <Indigenas_BOT>, follow these steps:

Windows:

>1. If you have git:
>> 1. Open your cmd;
>> 2. Type the following command:
>``` 
>git clone https://github.com/Junior-Winchester/Indigenas-BOT
>```
>2. If you don't have git:
>>1. Go to the top of this page;
>>2. Click on the code button and select Download ZIP, and wait the download finish;
>>3. Click with the right button on zip file that you have downloaded, and select the Extract Here option;
>>
* <strong>Don't forget to change the Google API Token and the Discord Token in config.json</strong>

## ☕ Using <Indigenas_BOT>

To use <Indigenas_BOT>, follow these steps:

Windows:
> 1. In cmd, open the bot's folder;
> 2. Type <strong>ONE</strong> of the following commands:
>```
>node index.js
>OR
>node .
>```
> 3. And that's it! Your bot is online

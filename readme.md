## 🚀 Instalando o <Indigenas_BOT>

Para instalar o <Indigenas_BOT>, siga estes passos:

Windows:

>1. Se você tem o Git:
>> 1. Abra seu CMD;
>> 2. Digite o seguinte comando:
>```
>git clone [https://github.com/Junior-Winchester/Indigenas-BOT](https://github.com/Junior-Winchester/Indigenas-BOT)
>```
>2. Se você não tem o Git:
>>1. Vá para o topo desta página;
>>2. Clique no botão "Code" (Código) e selecione "Download ZIP", e espere o download finalizar;
>>3. Clique com o botão direito no arquivo zip que você baixou e selecione a opção "Extract Here" (Extrair Aqui);
>>
* **Não se esqueça de alterar o Token da Google API e o Token do Discord em `config.json`**

---

## ☕ Usando o <Indigenas_BOT>

Para usar o <Indigenas_BOT>, siga estes passos:

Windows:
> 1. No CMD, abra a pasta do bot;
> 2. Digite **UM** dos seguintes comandos:
>```
>node index.js
>OU
>node .
>```
> 3. E pronto! Seu bot está online.
